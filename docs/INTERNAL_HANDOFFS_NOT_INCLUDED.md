# Internal handoffs not included

Detailed TRACE-VLA run handoffs, workstation paths, HPRC job paths, raw rollout notes, and agent scratch reviews are intentionally not committed in this pre-publication TRACE-VLA repository.

Keep this GitHub repo focused on reusable TRACE-VLA code, schemas, examples, and sanitized workflow documentation. Store raw experiments, checkpoints, logs, and local handoff notes outside the repository or under ignored local paths.
